### Relationship to MiSTer-VCMI, MiSTer-DCSS, MiSTer-Raster and MiSTer-Phosphor

MiSTer-Raster and MiSTer-Phosphor are FPGA cores. MiSTer-GemRB is ARM (HPS) software and shares no source with them. It
shares the SDL2 video and audio drivers of **MiSTer-VCMI**, which are not copied into this repository:
`scripts/build-deps.sh` reads them from `../MiSTer-VCMI/sdl-driver` (or `SDL_DRIVER_DIR`). Their licensing is described in
that project's `ATTRIBUTIONS.md`: they are offered under GPL-2.0-or-later and are compatible with SDL's zlib license
when built into the SDL library.

## GemRB

The engine is [GemRB](https://github.com/gemrb/gemrb), release 0.9.5 (commit `b33f0e7275ea1fc8a82459b418f6a7b5f1b40108`),
fetched by `scripts/build-gemrb.sh` and not stored in this repository. It is licensed GPL-2.0-or-later (its `COPYING`
is the GPL version 2). The GemRB project's own documentation and authors file describe its contributors.

- The Bink video plugin (`BIKPlayer`) contains code derived from FFmpeg (for example `rdft.cpp`), which is licensed
  LGPL-2.1-or-later; its file headers say so.
- GemRB bundles the {fmt} formatting library (MIT license, Victor Zverovich); the license text is in the header
  `fmt/format.h` and is included in `LICENSES/fmt-MIT.txt` in the release.
- Other bundled code in GemRB keeps the license stated in its file headers.

### Patches to GemRB

The files in `patches/` (`0001-*`, `0002-*`) are modifications of GemRB and remain under GemRB's GPL-2.0-or-later
license. They are applied by `scripts/build-gemrb.sh`.

- `0001-sdlaudio-lock-order-and-music-conversion.patch` — the SDL audio plugin's channel manager no longer holds its
  lock while calling into SDL_mixer (which took SDL's audio lock in the opposite order and could deadlock the game),
  and music is converted to the device format with a stateful `SDL_AudioStream` instead of chunk-by-chunk, which
  produced odd-length chunks and shifted the alignment of everything after them. Sound-effect buffers use their exact
  converted length.
- `0002-sdlvideo-software-renderer-blend-fallbacks.patch` — detects that SDL's software renderer has no custom blend
  modes; then skips the wall-occlusion stencil pass and approximates three glow blend modes with SDL's additive blend.

## SDL and SDL_mixer

[SDL2](https://libsdl.org) 2.32.10 and SDL2_mixer 2.8.1 are distributed under the zlib license (`COPYING.ZLIB` is SDL's
license text and notice). Both are built as shared libraries. SDL2 is built with MiSTer-VCMI's video and audio drivers and
its two patches (`sdl2-mister-hooks.patch` and `sdl2-resampler.patch`), plus three patches from this project. SDL2_mixer
is built with WAV support only; GemRB decodes its own audio formats and hands PCM to it.

The SDL patches in `patches/sdl2/` are modifications of SDL and remain under SDL's zlib license. Altered source
versions must be plainly marked as such, and the patches are that marking.

- `neon-blit-opaque-dst.patch` — SDL's NEON alpha blitter (`BlitRGBtoRGBPixelAlphaARMNEON`, from pixman) leaves the
  destination alpha alone, where the C blitter blends it. The patch selects it only when the destination has no alpha
  channel. The NEON blitters are switched on by the build (`-DSDL_ARMNEON=ON`).
- `triangle-no-int64-divide.patch` — the software triangle rasterizer divided by the triangle's area four times per
  pixel; it now multiplies by a precomputed reciprocal.
- `blendfillrect-neon.patch` — a NEON version of the translucent rectangle fill for ARGB8888, bit-identical to the C code.

## Runtime shipped in the bundle

The MiSTer's root filesystem has an old glibc (2.31), so the bundle carries its own runtime and starts the programs
through its own dynamic loader (`patchelf` sets the interpreter to `/media/fat/gemrb/libs/ld-linux-armhf.so.3`).

- **glibc 2.43** (Ubuntu) — `ld-linux-armhf.so.3`, `libc.so.6`, `libm.so.6`, and the charset conversion modules under
  `libs/gconv` (from Ubuntu's `libc6_2.43-2ubuntu2_armhf.deb`). License: LGPL-2.1-or-later. The programs link to it
  dynamically, so it can be replaced by the user.
- **libstdc++ and libgcc_s** (GCC 15.2, Ubuntu cross toolchain). License: GPL-3.0-or-later with the GCC Runtime Library
  Exception 3.1.

## MiSTer platform references

The framebuffer and audio drivers were written from reading the MiSTer sources; no source was copied from them. See
MiSTer-VCMI's `ATTRIBUTIONS.md` for details.

- [Main_MiSTer](https://github.com/MiSTer-devel/Main_MiSTer) (GPL-3.0) — the `fb_cmd*` and `video_mode` commands on
  `/dev/MiSTer_cmd`, and how F9 and scripts switch the scaler to the Linux framebuffer.
- [Linux-Kernel_MiSTer](https://github.com/MiSTer-devel/Linux-Kernel_MiSTer) (GPL-2.0) — `MiSTer_fb.c` and
  `MiSTer-audio-spi.c`, which define the `/dev/fb0` frame reader and the `/dev/MrAudio` ring buffer.

## Game data

Baldur's Gate II and every other Infinity Engine game's data files are not included and are not licensed by this
project. You need your own copy (the GOG "Complete" release was used); they are extracted with
[innoextract](https://constexpr.org/innoextract/) and copied to the device by `scripts/deploy.sh data`.

## Redistribution checklist

When publishing source or a bundle:

1. Include `LICENSE.txt`, `COPYING.ZLIB` and this document with the corresponding source distribution.
   `scripts/release.sh` does this for the release zip and also adds each component's license text under `LICENSES/` and
   a `SOURCES.txt` with the exact source versions and checksums.
2. Preserve all per-file copyright and license headers in GemRB, SDL and the libraries above.
3. Make the complete corresponding source available: this repository, MiSTer-VCMI (for the SDL drivers), and the pinned
   upstream releases the scripts fetch (GemRB 0.9.5, SDL2, SDL2_mixer, Python, zlib, libpng, FreeType, libogg,
   libvorbis).
4. For a binary bundle, also ship the license texts of each bundled component, and make the glibc and GCC runtime
   sources available (Ubuntu source packages `glibc`, `cross-toolchain-base` and `gcc-15-cross`).
5. Do not include Baldur's Gate II data.

This inventory documents the repository as audited; it is not legal advice.
