# MiSTer-GemRB v0.2.0

Five classic Infinity Engine games now run, each with its own launcher: **Baldur's Gate**, **Baldur's Gate II**,
**Planescape: Torment**, **Icewind Dale** (with Heart of Winter and Trials of the Luremaster) and **Icewind Dale II**.
It is [GemRB](https://gemrb.org) 0.9.5 running on the ARM side of a MiSTer (DE10-Nano) as an ordinary Linux program;
nothing is installed outside `/media/fat`. You need your own copy of each game's data: it is not included.

## Read this before upgrading

- **A USB drive is now required for swap memory.** Plug in a drive formatted as **ext4** with at least 500 MB free
  before starting a game. The launcher adds one file, `gemrb-swapfile` (384 MB), to it and never erases or formats
  anything. If no drive is found, the launcher says so and waits until you plug one in. The swap file used to live on the
  SD card; that is gone, because the SD card is mounted synchronously, which made swapping very slow (loading a new area
  could stall the game for about a minute) and wears the card. The old `swapfile` on the SD card is deleted for you the
  first time you start a game. FAT32 drives cannot be used: creating the file on them runs at about 0.1 MB/s.
- Each game has its own folder (`games/<game>`), saves (`saves/<game>`), cache and settings (`GemRB-<game>.cfg`).
  A 0.1.0 install is moved into this layout automatically on the first run.

## Install

1. Unzip `MiSTer-GemRB-v0.2.0.zip` onto the root of the MiSTer's SD card, merging with what is there. This creates
   `/media/fat/gemrb` and one launcher per game in `/media/fat/Scripts`: `gemrb-bg2`, `gemrb-bg1`, `gemrb-pst`,
   `gemrb-iwd` and `gemrb-iwd2`.
2. Copy each game you own into `/media/fat/gemrb/games/<game>`: `bg2`, `bg1`, `pst`, `iwd`, `iwd2`. For the GOG
   releases, unpack the installer with [innoextract](https://constexpr.org/innoextract/) and copy the game folder.
   Planescape and Icewind Dale II also need the `.ini` files from the installer's `__support/app` folder copied into
   the game folder, and Icewind Dale II unpacks without an `app` folder. Each game is 1.4 to 2.6 GB. The
   [README](https://github.com/aquasock/MiSTer-GemRB#supported-games) has a table with the details.
3. Plug in the swap drive, then on the MiSTer press F12, choose **Scripts** and run a launcher.

## What is new

- **Baldur's Gate, Planescape: Torment, Icewind Dale and Icewind Dale II** (new). Each was started on a MiSTer, and
  navigated for a while. Details per game are in the README. Icewind Dale II has no 640x480 layout and always uses
  800x600.
- **A resolution question at launch**, 640x480 or 800x600, then the HDMI output switches to that size (your display
  scales it to fill the screen) and back to 1080p60 afterwards.
- **USB swap** as described above, attached directly to the swap system so it is not slowed by the drive's synchronous
  mount.
- **Less memory:** the C library's allocator is tuned to hold on to less freed memory.
- **A crash no longer leaves a black screen.** The launcher resets the console when the game ends however it ended, so
  its prompts are visible again.
- **`last-run.log`** records each run's exit code and free memory. **Developer options** (`MISTER_DEBUG`,
  `MISTER_MALLOC_CHECK`) run the game under gdb and write `crash.log`; they need extra files that are not in the zip.
- The shared MiSTer SDL driver rescans input devices without opening all of them every 1.5 seconds.

## Known limitations

- **One crash is known and not fixed.** In Baldur's Gate II: Throne of Bhaal, a scripted encounter where an enemy starts a
  cutscene and then summons Kobold Commandos can abort the game a few seconds into the fight with a glibc heap error,
  right after one of their shots misses. Summoned dogs in the same encounter do not trigger it. Audio, this port's SDL
  speed-ups, the swap file and the allocator settings were each ruled out by switching them off, so it is most likely a
  bug in GemRB 0.9.5 itself. Save before scripted fights. Tested at 640x480 only.
- **Only short sessions were played in most games.** Baldur's Gate II has had the most play. The other four were
  checked for a while each, not played through. The Enhanced Editions, mods and multiplayer are untested.
- The GOG edition of Planescape: Torment has no movie files, so its videos are missing.
- About 20 fps in busy scenes, and videos stutter; both are limits of the CPU.
- Characters are drawn in front of walls and trees (SDL's software renderer lacks the blend modes GemRB uses to hide
  them), and the fog of war has the original game's blocky style.
- Your original HDMI mode is not saved; the launcher restores 1080p60. Set `MISTER_RESTORE_MODE` in
  `/media/fat/gemrb/env.sh` if yours differs.
- GemRB ignores `SIGTERM`; quit from the game menu.

## Licensing and source

Original project code is GPL-2.0-or-later, and so is the package as a whole. `gemrb/LICENSES/` has the license text of
every component, `gemrb/ATTRIBUTIONS.md` explains what each is used for, and `gemrb/SOURCES.txt` lists the exact
source versions and their SHA-256 checksums. The SDL2 drivers come from
[MiSTer-VCMI](https://github.com/aquasock/MiSTer-VCMI). The bundle carries its own glibc and C++ runtime (dynamically
linked).

Verify the download with `SHA256SUMS`.
