# MiSTer-GemRB v0.1.0

First public preview. It runs [GemRB](https://gemrb.org) 0.9.5, the open-source Infinity Engine, on the ARM side of a
MiSTer (DE10-Nano), and plays Baldur's Gate II. The game is an ordinary Linux program; nothing is installed outside
`/media/fat`. You need your own copy of the game data: it is not included.

## Install

1. Unzip `MiSTer-GemRB-v0.1.0.zip` onto the root of the MiSTer's SD card, merging with what is there. This creates
   `/media/fat/gemrb` and `/media/fat/Scripts/gemrb.sh`.
2. Copy your game files into `/media/fat/gemrb/game` (the folder that contains `CHITIN.KEY`, `dialog.tlk`, `data/`,
   `override/`, `music/`, `sounds/` and `scripts/`). For the GOG release, unpack the installer with
   [innoextract](https://constexpr.org/innoextract/) and copy the contents of its `app` folder; the installer's `.exe`
   and `.dll` files and the manuals are not needed. Allow about 2.6 GB.
3. On the MiSTer press F12, choose **Scripts**, and run **gemrb**.

The screen blinks as the HDMI output switches to 800x600, which your display scales to fill the screen. Quit from the
game's own menu and the launcher switches your display back to 1080p60. On the first run the launcher creates a 384 MB
swap file in the background (about 40 seconds); see the README. Full instructions are in `gemrb/INSTALL.txt` and the
[README](https://github.com/aquasock/MiSTer-GemRB#readme).

You need a MiSTer with a DE10-Nano, a USB mouse and keyboard, and an HDMI display that accepts 800x600 at 60 Hz.

## What works

- Baldur's Gate II (Shadows of Amn and Throne of Bhaal, GOG "Complete"): menus, character creation, exploring, fights,
  dialogue, the game-over video, exiting cleanly. Mouse and keyboard, with USB hotplug.
- Music and sound effects through the MiSTer's audio path (HDMI and analog).
- The game's own videos, decoded by GemRB (they stutter; the intro videos are skipped by default).
- Nothing needs `MiSTer.ini` changes and nothing outside `/media/fat` is touched.

Measured at 800x600: the main menu runs at about 29 fps (the game caps at 30); busy scenes in the game run at about
20 fps after the optimizations (they started at 8 to 12). Memory use is about 200 MB after loading and up to about
380 MB in a large fight, so the launcher keeps an emergency swap file.

## Known limitations

- Only Baldur's Gate II has been tested. Other GemRB games, Enhanced Editions, mods and multiplayer have not.
- About 20 fps in busy scenes; videos stutter.
- Characters are drawn in front of walls and trees (SDL's software renderer lacks the blend modes GemRB uses to hide
  them), and the fog of war has the original game's blocky style.
- Your original HDMI mode is not saved; the launcher restores 1080p60. Set `MISTER_RESTORE_MODE` in
  `/media/fat/gemrb/env.sh` if yours differs.
- GemRB ignores `SIGTERM`; quit from the game menu.

## Licensing and source

Original project code is GPL-2.0-or-later, and so is the package as a whole. `gemrb/LICENSES/` has the license text of
every component, `gemrb/ATTRIBUTIONS.md` explains what each is used for, and `gemrb/SOURCES.txt` lists the exact
source versions and their SHA-256 checksums. The SDL2 drivers come from
[MiSTer-VCMI](https://github.com/aquasock/MiSTer-VCMI). The bundle carries its own glibc and C++ runtime (dynamically
linked).

Verify the download with `SHA256SUMS`.
